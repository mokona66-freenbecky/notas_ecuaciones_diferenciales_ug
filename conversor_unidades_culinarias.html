Conversor de unidades para arte culinario en Excel (VBA + UserForm)

Pensamiento lógico paso a paso para construir una herramienta que convierta: Temperatura, Masa (Peso) y Volumen. Todo el código vive dentro del propio UserForm — no se necesita un módulo aparte con funciones.

Paso 1. Definir el problema y el alcance

Antes de programar nada, se define qué debe hacer la herramienta:

  • El usuario elige una categoría de conversión (Temperatura, Masa o Volumen).
  • Según la categoría, se llenan las listas de unidades de origen y destino.
  • El usuario captura la cantidad y presiona "Convertir".
  • El resultado se muestra en un cuadro que no se puede editar a mano.
  • Se valida que lo escrito sea un número, y se acepta tanto punto como coma decimal (ej. "36,6" o "36.6").

Paso 2. Elegir una unidad base por magnitud

Para no escribir una fórmula por cada par posible de unidades, el truco es convertir siempre hacia una unidad base y de ahí hacia la unidad destino.

Paso 5. Código VBA completo (todo va dentro del UserForm)

Este bloque hace tres cosas: llena las categorías al abrir el formulario, actualiza las listas de unidades según la categoría elegida, y hace la conversión al presionar el botón.

Private Sub UserForm_Initialize()
    ' 1. Llenar las categorías al abrir el formulario
    cmbCategoria.AddItem "Temperatura"
    cmbCategoria.AddItem "Masa (Peso)"
    cmbCategoria.AddItem "Volumen"
End Sub

Private Sub cmbCategoria_Change()
    ' 2. Cambiar las unidades disponibles según la categoría elegida
    cmbDe.Clear
    cmbA.Clear
    txtValorIn.Value = ""
    txtResultado.Value = ""

    Select Case cmbCategoria.Value
        Case "Temperatura"
            cmbDe.List = Array("Celsius", "Fahrenheit")
            cmbA.List = Array("Celsius", "Fahrenheit")
        Case "Masa (Peso)"
            cmbDe.List = Array("Gramos", "Kilogramos", "Onzas", "Libras")
            cmbA.List = Array("Gramos", "Kilogramos", "Onzas", "Libras")
        Case "Volumen"
            cmbDe.List = Array("Mililitros", "Litros", "Tazas", "Cucharadas", "Cucharaditas")
            cmbA.List = Array("Mililitros", "Litros", "Tazas", "Cucharadas", "Cucharaditas")
    End Select
End Sub

Private Sub btnConvertir_Click()
    ' 3. Lógica matemática de las conversiones
    Dim valorIn As Double
    Dim valorOut As Double
    Dim baseConvertida As Double

    ' Validar que se haya ingresado un número
    If Not IsNumeric(txtValorIn.Value) Then
        MsgBox "Por favor, ingresa un número válido.", vbExclamation, "Error"
        Exit Sub
    End If

    ' Cambiar comas por puntos si es necesario y convertir a decimal
    valorIn = CDbl(Replace(txtValorIn.Value, ",", "."))

    ' --- TEMPERATURA ---
    If cmbCategoria.Value = "Temperatura" Then
        If cmbDe.Value = "Celsius" And cmbA.Value = "Fahrenheit" Then
            valorOut = (valorIn * 9 / 5) + 32
        ElseIf cmbDe.Value = "Fahrenheit" And cmbA.Value = "Celsius" Then
            valorOut = (valorIn - 32) * 5 / 9
        Else
            valorOut = valorIn ' Si eligen la misma unidad
        End If
        txtResultado.Value = Round(valorOut, 2)
        Exit Sub
    End If

    ' --- MASA (Truco: Convertimos todo a gramos primero) ---
    If cmbCategoria.Value = "Masa (Peso)" Then
        Select Case cmbDe.Value
            Case "Gramos": baseConvertida = valorIn
            Case "Kilogramos": baseConvertida = valorIn * 1000
            Case "Onzas": baseConvertida = valorIn * 28.3495
            Case "Libras": baseConvertida = valorIn * 453.592
        End Select

        Select Case cmbA.Value
            Case "Gramos": valorOut = baseConvertida
            Case "Kilogramos": valorOut = baseConvertida / 1000
            Case "Onzas": valorOut = baseConvertida / 28.3495
            Case "Libras": valorOut = baseConvertida / 453.592
        End Select
        txtResultado.Value = Round(valorOut, 2)
        Exit Sub
    End If

    ' --- VOLUMEN (Truco: Convertimos todo a mililitros primero) ---
    If cmbCategoria.Value = "Volumen" Then
        Select Case cmbDe.Value
            Case "Mililitros": baseConvertida = valorIn
            Case "Litros": baseConvertida = valorIn * 1000
            Case "Tazas": baseConvertida = valorIn * 240 ' Taza métrica estándar
            Case "Cucharadas": baseConvertida = valorIn * 15
            Case "Cucharaditas": baseConvertida = valorIn * 5
        End Select

        Select Case cmbA.Value
            Case "Mililitros": valorOut = baseConvertida
            Case "Litros": valorOut = baseConvertida / 1000
            Case "Tazas": valorOut = baseConvertida / 240
            Case "Cucharadas": valorOut = baseConvertida / 15
            Case "Cucharaditas": valorOut = baseConvertida / 5
        End Select
        txtResultado.Value = Round(valorOut, 2)
        Exit Sub
    End If
End Sub

A diferencia de generar cada evento uno por uno, aquí basta con hacer doble clic en cualquier parte vacía del UserForm. Eso abre la ventana de código ya posicionada dentro del formulario: borras el contenido que trae por defecto y pegas el bloque completo del Paso 5.

Doble clic en el UserForm → ventana de código

2Selecciona todo el código que aparece (Ctrl+A) y bórralo
3Pega aquí (Ctrl+V) el bloque completo del Paso 5, con sus tres procedimientos

Nota los colores del código correctamente escrito: azul para palabras clave (Private Sub, If, Select Case, End...), negro para el resto. Los comentarios con apóstrofo (') se ven en verde.

Resumen ordenado de todo el montaje:

  1. Abrir el editor VBA (Alt + F11) — Paso 6A.
  2. Insertar un UserForm, colocar los controles del Paso 4 y renombrarlos en Propiedades — Paso 6B, 4B y 4C.
  3. Doble clic en el UserForm y pegar el código completo del Paso 5 — Paso 5B.
  4. Insertar un Módulo con la macro AbrirConversor — Paso 6C.

Nota: extensión opcional "De Masa a Volumen"

Convertir de peso (gramos) a volumen (tazas) es el mayor reto en gastronomía porque depende de la densidad del ingrediente: no es lo mismo una taza de agua que una taza de harina.

Ingrediente1 taza equivale a
Agua240 g
Harina120 g
Azúcar200 g

Este código base maneja Masa y Volumen por separado, sin cruzarlos. Para hacer conversiones cruzadas de Masa a Volumen habría que agregar un ComboBox extra, por ejemplo cmbIngrediente, con una tabla de densidades (harina, azúcar, mantequilla, cacao, etc.).
